# Progetto Drago e Cacciatore

Progetto realizzato in Java utilizzando la programmazione concorrente.

## Classi

- Drago: implementa Runnable e permette al drago di volare per un numero di battiti.
- Cacciatore: contiene il metodo per interrompere il thread del drago.
- Main: legge il numero di battiti, avvia il drago e lo osserva per 10 cicli.

Il cacciatore utilizza il metodo interrupt() per colpire il drago.
